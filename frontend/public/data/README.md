# 警鐘地名データセット（静的配信ファイル）

`backend/packages/alg` のパイプラインが生成したファイルです。手で編集せず、
`cd backend && make build-data` で再生成してください。

## ファイル

| ファイル | 内容 |
|---|---|
| `toponyms.geojson` | 出典で裏づけた地名（根拠レベル1以上）。地図が最初に読む |
| `candidates/{都道府県コード}.geojson` | 表記が要素辞書に一致するだけの候補（根拠レベル0）。全国 |
| `areas/{都道府県コード}.geojson` | 地名がカバーする範囲（国勢調査の町丁・字等ポリゴン）。拡大時に遅延読み込み |
| `details/{id}.json` | 1件ごとの全情報（根拠の引用・出典・ハザード照合・異説） |
| `monuments.geojson` | 自然災害伝承碑（国土地理院） |
| `elements.json` | 地名要素辞典（替字を含む形態素と意味） |
| `sources.json` | 出典一覧 |
| `stats.json` | 集計（根拠レベル別・災害種別・都道府県別・要素別） |
| `meta.json` | ビルド日時と出典表記 |

## 根拠レベル

| レベル | 意味 |
|---|---|
| 0 | 字面のみ。要素辞書に一致するだけの候補。災害履歴を示すとは限らない |
| 1 | 地名辞典・地誌が地形（崖・窪地・低湿地など）由来と記載 |
| 2 | 地方史・地名考・自治体資料などが災害由来または替字であることを明記 |
| 3 | 年号を伴う実際の災害、伝承碑、口承と対応 |

`disputed` が真の項目は、出典自身が由来に疑義を示しています。反証も
`evidence` に `stance: "disputes"` として収録しています。

## 範囲（areas）について

地名が指すのは点ではなく広がりです。小字の境界は全国では公開されていないため、
公開されている最も細かい単位である町丁・字等のポリゴンで代替しています。
各地名の `areaKey` が `areas/*.geojson` の `key` に対応します。
点は範囲の代表点であり、地名が指す場所そのものではありません。
`precision` にどの解像度で位置を決めたかを記録しています。

## 出典と利用条件

このデータセットは以下を出典としています。二次利用の際は各出典の
利用条件に従い、出典を明示してください。

- **地理院タイル**（国土地理院） — 背景地図。国土地理院コンテンツ利用規約
- **重ねるハザードマップ**（国土交通省・国土地理院） — 土砂災害警戒区域・浸水想定区域。
  ハザードマップポータルサイト利用規約
- **自然災害伝承碑**（国土地理院） — 国土地理院コンテンツ利用規約
- **Geolonia 住所データ** — CC BY 4.0
- **令和2年国勢調査 小地域（町丁・字等別）境界データ**（総務省統計局 e-Stat） —
  地名がカバーする範囲の描画に使用
- **歴史地名データ**（人間文化研究機構・H-GIS研究会） — 出典明示のうえ自由利用
- **自治体の地名考・防災資料**（桐生市立図書館『桐生市地名考』、豊川市資料など） —
  書誌情報と根拠となる短い引用のみを収録。本文は再配布していません
- **学術文献・書籍** — 書誌情報のみを収録

全出典は `sources.json` および サイトの「出典」ページに掲載しています。

## 注意

災害地名は後から語り直されることがあります。磯田(2018)は、生き残る災害地名は
話として面白くするために尾ひれをつけたものではないかと指摘しています。
根拠レベルと `disputed` を必ず併せて解釈してください。
